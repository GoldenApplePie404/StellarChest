# StellarChest
星之匣是一个面向视觉小说（Galgame / Visual Novel）创作者与玩家的一站式 Web 平台，集成星河工坊（项目引擎）、星墨（脚本编辑器 + Monaco + 流程图）、星灵（AI 剧本续写与素材生成）、星尘库（立绘/背景/音效分类素材库）、星工坊（图片与音频处理工具）、在线预览（Canvas + CSS 混合渲染引擎）与星语（创作论坛社区）七大功能模块，覆盖从创意构思、脚本编写、素材管理到作品发布与交流的完整创作闭环。平台内置 48 个脚本指令，支持分支剧情、变量事件、角色动画等交互逻辑，AI 模块允许用户自配置 API Key。

可以跟[Godot-Galgame-Framework](https://github.com/GoldenApplePie404/Godot-Galgame-Framework) 搭配使用
